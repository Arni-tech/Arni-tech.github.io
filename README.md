# Arnav Negi | Portfolio

Personal portfolio site for Arnav Negi, a University of Queensland Computer Science graduate working across machine learning, data science, AI applications and software development.

Live site: https://arni-tech.github.io/

## What's here

- `index.html`: the whole site (HTML, CSS and JavaScript in one file, no build step)
- `Arnav_Negi_Resume.pdf`: the resume linked from the "Download résumé" button
- `images/experience`, `images/leadership`, `images/life`: photos used on the page
- `images/honors`: certificates and badges linked from the Selected Achievements section

## Editing

Everything lives in `index.html`. Colours and fonts are CSS variables at the top of the `<style>` block (`--bg`, `--coral`, `--teal` and so on).

A few photo slots are commented out until the images are added. Search `index.html` for "Photo not uploaded yet", add the file with the name shown, then remove the comment markers around that block.

## Deploying

The site is served by GitHub Pages from the `main` branch. Commit and push to `main`, and the live site updates within a minute or two.
